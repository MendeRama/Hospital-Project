# Hospital Performance & Patient Analytics Dashboard
# Introduction
This project presents a data-driven analytics solution for monitoring hospital performance and patient trends using an interactive dashboard.
It focuses on analyzing key healthcare metrics such as admissions, readmissions, treatment costs, and patient segmentation to support data-informed decision-making in hospital operations.
# Problem Statement
Hospitals generate large volumes of data, but extracting meaningful insights for operational and clinical decisions is challenging.
This project aims to simplify healthcare data analysis by building a centralized dashboard that provides clear, actionable insights.
# Solution
Developed an end-to-end analytics workflow that includes:
- Data preprocessing and cleaning
- Exploratory data analysis (EDA)
- Interactive dashboard development
- The final output is a Power BI dashboard that enables users to explore hospital data dynamically.
# Dashboard Overview
The dashboard provides insights into:
- Patient Metrics: Total admissions, total patients
- Operational Metrics: Bed occupancy, length of stay
- Clinical Metrics: Readmission rate, mortality rate
- Financial Metrics: Revenue and treatment cost
- Segmentation: Age group, gender, chronic conditions
- Department Analysis: Performance across departments
- Interactive filters allow users to drill down by hospital, department, doctor, insurance plan, gender, and age group.

# Key Insights
- Higher readmission rates observed in critical care departments
- Chronic conditions significantly contribute to hospital admissions
- Middle-aged patients form the majority of admissions
- Noticeable variation in revenue across insurance types
